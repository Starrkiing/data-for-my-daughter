## The idea

Data, begin with a tiny playable prototype. Learn how the game systems fit together before attempting a complete game.

Use new characters, names, maps, pictures, and sounds. The example title **Garden Elevator** and all example rules below are our own proposed design. Teacher can choose different characters later.

The official Dandy's World description establishes teamwork, Toons, machines, descending into Gardenview Center, and character abilities. It does not document the original game's source code or exact implementation. Source: https://www.roblox.com/games/16116270224/Dandys-World

## First playable version

Build one room with an elevator, three repair stations, one player, and one roaming creature.

1. Move around the room.
2. Stand beside a repair station and hold the repair button until it is finished.
3. Avoid the creature while repairing the stations.
4. Once all three stations are finished, return to the elevator.
5. Reach the elevator before the escape timer runs out to enter the next floor.
6. Finish three floors to win. Lose all hearts, or miss the elevator, and the run ends.
7. A restart button begins a clean run.

These numbers are prototype choices, not claims about Dandy's World's exact rules.

## Build in small steps

### 1. Movement and walls
Add a player, walls, and collision. Confirm the player can move and cannot walk through walls. Make movement independent of screen frame rate.

### 2. Repair stations
Give each station progress from 0 to 100 percent. Repair only while the player is close and holds the button. Stop progress when the player leaves. A finished station cannot be counted twice.

### 3. Creature behavior
Use three states: patrol, chase, and return to patrol. The creature notices nearby players, navigates around walls, and gives up when they escape its detection range. Start with one simple room.

### 4. Hearts
Touching the creature removes one heart. Give a short protected period after a hit so one touch cannot remove every heart instantly. Zero hearts ends the run.

### 5. Elevator and floors
Keep four separate game states: playing, escaping, won, and lost. Completing the last repair starts the escape timer once. Only entering the elevator during escaping advances a floor. A new floor resets repair stations, creature position, escape time, and player position. Preserve surviving hearts. Never spawn the creature on the player.

### 6. One special ability
After the basic loop works, add an original character ability, such as a brief speed boost with a cooldown. Keep it simple enough to explain and test.

### 7. Polish
Display hearts, current floor, station progress, ability cooldown, and escape time. Add clear instructions, readable buttons, simple sounds, and a restart screen.

## A starting logic sketch

This is pseudocode, not executable game code:

```text
each update:
    if state is won or lost:
        wait for restart
    otherwise:
        move player using elapsed time and wall collision
        update creature
        apply at most one hit per damage cooldown
        if hearts are zero:
            state = lost
        otherwise:
            if state is playing:
                update nearby unfinished station while repair is held
                if all stations are finished:
                    state = escaping
                    escape_time = starting_escape_time
            else if state is escaping:
                reduce escape_time using elapsed time
                if escape_time is zero:
                    state = lost
                else if player is inside elevator:
                    if current floor is the final floor:
                        state = won
                    otherwise:
                        load next floor in playing state
```

## Choosing a building tool

- **Roblox version:** use Roblox Studio and Luau. Start with one player. Add cooperative multiplayer later; the server must own health, repairs, floor changes, and rewards, and validate client requests.
- **Browser practice version:** use a small HTML/JavaScript canvas prototype with original simple shapes. This can demonstrate the loop, but is not a Roblox experience.

Do not invent a claim that either version exists yet.

## Checks for a future implementation

Confirm that leaving a station stops repairs, finished stations count once, walls block movement, damage has a cooldown, zero hearts loses, the elevator stays inactive until repairs finish, the timer starts once, missing the elevator loses, floors advance once per escape, the final floor wins, and restart resets the run.
